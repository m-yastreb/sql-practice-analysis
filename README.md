# SQL Projects Portfolio

Коллекция SQL-проектов, выполненных в рамках обучения и практики. 
Все запросы написаны и протестированы на платформе Stepik (онлайн-тренажёр по SQL).

В работе с базой данных №1 показаны следующие навыки:

| Навык   | Что именно                                                   |
|---------|--------------------------------------------------------------|
| **SQL** | Многотабличные `JOIN` (`INNER`, `LEFT`, `RIGHT`)             |
|         | Агрегация: `GROUP BY`, `SUM`, `COUNT`, `AVG`                 |
|         | фильтрация и сортировка (WHERE, ORDER BY, LIKE, IS NOT NULL) |
|         | Подзапросы и производные таблицы                             |
|         | `UNION ALL`, `USING`                                         |
|         | Работа с датами: `DATEDIFF`, `YEAR`, `MONTHNAME`             |
|         | Условная логика: `IF`, `ABS`                                 |
|         | Псевдонимы                                                   |
|         | Изменение данных: INSERT INTO ... SELECT, UPDATE ... JOIN    |


В работе с базой данных №2 показаны следующие навыки:

| Навык   | Что именно                                                     |
|---------|----------------------------------------------------------------|
| **SQL** | Фильтрация групп: HAVING.                                      |
|         | Удаление данных: DELETE.                                       |
|         | Создание таблиц: CREATE TABLE с FOREIGN KEY, ON DELETE CASCADE |
|         | Случайная выборка: ORDER BY RAND(), LIMIT.                     |
|         | Работа со строками: CONCAT, LEFT.                              |
|         | Подсчёт уникальных значений: COUNT(DISTINCT ...).              |
|         | Округление: ROUND                                              |
|         | Скалярные подзапросы в WHERE, INSERT, UPDATE                   |
|         | Работа с датами: NOW().                                        |
